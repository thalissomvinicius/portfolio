# Auto-run Workflow

Este workflow permite que o assistente execute comandos automaticamente.

// turbo-all

## Comandos frequentes

1. Iniciar backend:
```bash
cd backend && python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

2. Iniciar frontend:
```bash
cd frontend && npm run dev
```

3. Instalar dependências Python:
```bash
pip install [pacote]
```

4. Instalar dependências NPM:
```bash
npm install [pacote]
```

5. Executar comandos de build/test conforme necessário
