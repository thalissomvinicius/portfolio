# Portfólio — Thalissom Vinicius

Portfólio profissional focado em sistemas, dados e automação aplicados a operações industriais e agrícolas.

## Posicionamento

Atualmente na Vila Nova Agroindustrial, desenvolvo produtos internos que conectam processos de campo, dados operacionais e decisões de gestão. Os cases são apresentados sem dados sensíveis ou detalhes que comprometam a operação da empresa.

## Projetos apresentados

- Ecossistema de operação agrícola;
- Controle de cotas CFF integrado à balança;
- Aplicativo Android de coletas offline-first;
- Painéis de qualidade, fertilizantes e inteligência geográfica;
- Projetos anteriores de automação para o mercado imobiliário.

## Tecnologias

React, Next.js, React Native, Python, SQL, Supabase, Cloudflare D1, Power BI e ferramentas geoespaciais.

## Desenvolvimento local

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run build
npm run lint
```
